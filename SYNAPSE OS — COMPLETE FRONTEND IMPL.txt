47. What AGY must NOT do

Put this explicitly in the implementation prompt.

DO NOT:

create fake/mock Cline execution
hard-code agent types
hard-code team roles
invent tool types
put Cline API calls in React components
create separate WebSockets per component
create frontend-only execution state
expose hidden chain-of-thought
make chat bypass policies
allow frontend authorization decisions
assume every action is reversible
create fake simulation results
create fake "AI activity" animations
poll every component independently
duplicate backend database state
make the UI dependent on raw Cline event structures
invent APIs that don't exist in the backend
make the UI look complete by using static demo data
