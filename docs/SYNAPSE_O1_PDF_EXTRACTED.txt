Important: Synapse should not fork Cline and then rewrite Cline's internals unnecessarily. 
Instead: 
upstream Cline 
     ↓ 
minimal Synapse patches 
     ↓ 
Cline Engine 
     ↓ 
Synapse Adapter 
     ↓ 
Synapse Control Plane 
This makes upstream rebasing possible. 
Cline's own architecture already puts stateful orchestration in @cline/core, the agent loop in 
@cline/agents, provider handling in @cline/llms, and shared contracts in @cline/shared.

39. Cline CLI 
Because we're forking the repository, the CLI is no longer something the customer installs.

decides when/how they are exposed.
